# 테트리스 보드

[게임 바로 시작](https://zero-sugars.github.io/tetris-board/)

8×8 판에서 가로나 세로로 8칸을 채우는 블록 퍼즐입니다. 순차 배치에서는 다음 조각을 미리 볼 수 있고, 3개 중 선택에서는 세 조각을 원하는 순서로 놓을 수 있습니다. 두 모드의 점수와 진행 상황은 각각 저장합니다.

조각을 끌어 놓거나 보드의 빈칸을 클릭하세요. Q는 왼쪽 회전, E와 마우스 우클릭은 오른쪽 회전입니다. 한 게임에서 세 번까지 되돌릴 수 있습니다.

## 패치와 공유

게임 한 편이 최상위 폴더의 `index.html`에 들어 있습니다. 수정한 `index.html`을 `main` 브랜치에 커밋하면 GitHub Pages가 같은 주소에 새 버전을 자동 배포합니다. 카페나 블로그에는 위의 플레이 링크를 공유하세요.
